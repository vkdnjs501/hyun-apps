Hyun-apps

현장에서 만든 웹앱을, 움직임이 살아 있는 한 화면에.

> **Built to Work. Made to Move.**

Hyun-apps는 직접 개발한 실용적인 웹앱들을 좌우로 넘겨보며 탐색하는 인터랙티브 포트폴리오입니다.

자전거 현장의 재고관리부터 피팅, 공기압 계산, 비파괴검사 학습까지. 일과 학습에서 마주한 문제를 해결하기 위해 만든 도구들을 한곳에 모았습니다.

단순히 링크를 나열하는 대신, 가로 카드 탐색과 프로젝트별 애니메이션으로 각 앱의 목적을 소개합니다. 관심 있는 프로젝트는 설명을 살펴본 뒤 앱을 열거나 GitHub 소스코드로 이동할 수 있습니다.

────────

✨ 주요 경험

한 화면에서, 좌우로

프로젝트를 한 장씩 넘겨보는 가로형 화면입니다. 스와이프·드래그·스크롤로 이동하면 카드가 자연스럽게 제자리에 정렬됩니다. 자동으로 다음 카드로 넘어가지 않아, 원하는 프로젝트를 자신의 속도로 살펴볼 수 있습니다.

움직임으로 드러나는 프로젝트의 개성

카드와 비주얼이 서로 다른 속도로 움직이는 패럴랙스, 순차적으로 나타나는 제목, 마우스 움직임에 반응하는 미세한 기울기를 적용했습니다. 프로젝트마다 달라지는 배경빛과 CSS/SVG 애니메이션으로 각 앱의 특징을 표현합니다.

화면에서 벗어난 카드의 장식 애니메이션은 일시 정지하며, 모션 ON / OFF로 움직임을 조절할 수 있습니다. 기기의 ‘동작 줄이기’ 설정을 우선합니다.

구경에서 실행까지

앱 열기로 해당 웹앱을 새 탭에서 열고, GitHub로 저장소를 확인할 수 있습니다. 프로젝트 이야기에서는 앱을 만든 목적과 주요 기능, 참고사항을 살펴봅니다.

🎮 탐색 방법

|조작          |사용 방법                          |
|:-----------|:------------------------------|

|**마우스·트랙패드**|드래그, 카드 위 세로 휠 또는 가로 스크롤       |

데스크톱·태블릿·스마트폰 화면에 맞춘 반응형 구성을 사용합니다. 화면이 매우 낮거나 확대된 환경에서는 내용과 버튼이 잘리지 않도록 세로 스크롤을 허용합니다.

🛠️ 구현과 관리

HTML · CSS · JavaScript로 제작한 정적 웹앱입니다. 외부 애니메이션 라이브러리나 프레임워크 없이 CSS 애니메이션과 JavaScript 인터랙션을 조합했으며, 별도 빌드 과정 없이 정적 호스팅에 배포할 수 있도록 구성했습니다.

프로젝트의 제목·설명·링크·순서·포인트색은 **projects.js**에서 관리합니다. 새로운 항목을 추가하면 카드와 내비게이션이 함께 생성됩니다. 실제 스크린샷을 등록해 소개용 비주얼을 교체할 수도 있습니다.

외부 폰트나 제3자 분석 도구를 사용하지 않습니다.

📌 참고사항

카드의 기본 그래픽은 소개용 CSS/SVG 비주얼이며, 실제 앱 스크린샷이나 실시간 재고·매출·측정 결과가 아닙니다. 포트폴리오 자체에는 실제 고객정보나 운영 데이터를 포함하지 않습니다.

현재 제공된 제작본 기준으로, 공개 배포 주소와 각 앱 실행 링크의 정상 접속은 별도 확인이 필요합니다. 실제 iPhone·iPad Safari 동작, 홈화면 설치 및 서비스워커의 오프라인 동작도 배포 후 검증 대상입니다. 포트폴리오의 오프라인 구성은 연결된 모든 앱의 오프라인 실행을 의미하지 않습니다.
