# Hyun-apps

### 현장에서 만든 웹앱을, 움직임이 살아 있는 한 화면에.

> **Built to Work. Made to Move.**

**Hyun-apps**는 직접 개발한 실용적인 웹앱들을 좌우로 넘겨보며 탐색하는 인터랙티브 포트폴리오입니다.

자전거 현장의 재고관리와 피팅, 공기압 계산부터 비파괴검사와 논리 학습까지. 일과 학습에서 마주한 문제를 해결하기 위해 만든 도구들을 한곳에 모았습니다. 관심 있는 앱을 발견하고, 만든 이유를 살펴본 뒤, 원본 웹앱이나 GitHub 소스코드로 이동할 수 있습니다.

**현재 패키지: v1.2.2** · HTML / CSS / JavaScript · 정적 GitHub Pages 배포용

## ✨ 한 화면에서, 나의 속도로

가로 카드 탐색과 스크롤 스냅으로 프로젝트를 한 장씩 넘겨봅니다. 스와이프·드래그·휠·트랙패드·이전/다음 버튼·키보드 탐색을 제공하며, 자동으로 다음 카드로 넘어가지 않습니다.

카드와 비주얼이 서로 다른 속도로 움직이는 패럴랙스, 순차적으로 나타나는 제목, 포인터 기울기와 프로젝트별 배경빛을 적용했습니다. 모션은 기기의 동작 줄이기 설정과 관계없이 **항상 ON**입니다. 이전 버전에서 저장한 모션 OFF 값도 적용하지 않습니다. 화면 밖의 카드, 숨겨진 페이지, 열린 상세 패널 뒤의 장식 모션만 일시 정지하며 다시 표시하면 재개합니다. 운영체제나 브라우저 자체가 백그라운드 실행을 제한하는 경우까지 강제할 수는 없습니다.

**앱 열기**는 해당 웹앱을 새 탭에서 열고, **GitHub**는 소스 저장소로 연결합니다. **프로젝트 이야기**에서는 만든 목적과 주요 기능, 참고사항을 살펴봅니다.

## ✦ 논리탐험대 — 살아 있는 캐릭터 표지

> **정답보다 먼저, 생각하는 방법을.**

세 번째 카드에서는 **별이·단서·반디**의 원본 일러스트로 구성한 캐릭터 표지를 만날 수 있습니다. 이름 버튼을 누르면 선택한 프레임이 앞으로 이동하고, 배경과 주제명이 함께 바뀝니다. 제목·설명·실행 버튼은 같은 위치에 머뭅니다.

| 캐릭터 | 주제 |
| :--- | :--- |
| 별이 | 논리의 기본 법칙 |
| 단서 | 가설추론·귀추법 |
| 반디 | 반례로 검토하기 |

카드 진입 시 프레임이 펼쳐지고, 선택한 캐릭터만 작게 부유합니다. 다른 카드를 보거나 상세 패널을 열면 장식 모션을 일시 정지합니다. 논리 카드 재방문 시에는 긴 등장 연출을 반복하지 않습니다.

**바깥 카드는 스와이프로, 안쪽 캐릭터는 버튼으로** 조작합니다. 캐릭터 버튼에 포커스가 있을 때 좌우 화살표는 캐릭터를 선택하고, 바깥 탐색 영역에서는 프로젝트를 이동합니다. 자동 캐릭터 전환은 없습니다.

**[탐험 시작 ↗](https://vkdnjs501.github.io/LOGIC_EXPEDITION_GAME/)** · [원본 저장소](https://github.com/vkdnjs501/LOGIC_EXPEDITION_GAME)

이 표지는 **원본 일러스트를 활용한 소개 연출**입니다. 실제 게임 스크린샷이 아니며 학습 진도·생각 노트와 연동하지 않습니다. 실제 학습은 원본 앱에서 진행합니다. 게임을 iframe으로 삽입하거나 원본 게임의 스크립트를 실행하지 않습니다.

기본 화면에서는 한 화면 탐색을 유지합니다. 화면 높이가 매우 낮거나 크게 확대된 환경에서는 내용과 버튼이 잘리지 않도록 세로 스크롤을 허용합니다.

## 🛠️ 프로젝트 관리

프로젝트 제목·설명·링크·순서·포인트색은 **`projects.js`**에서 관리합니다. 항목을 추가하면 카드와 내비게이션이 함께 생성됩니다. 기존 프로젝트 ID는 외부에서 공유한 해시 링크에 사용되므로 가능한 유지하세요.

논리탐험대의 ID는 `logic-expedition`입니다. **현재 포트폴리오 실행 주소 뒤에 `#logic-expedition`을 붙이면** 해당 카드로 직접 들어갑니다. 배포 주소의 대소문자는 실제 Pages 주소를 기준으로 확인하세요.

선택적 `launchLabel`은 기본 ‘앱 열기’를 프로젝트별 문구로 바꿉니다. 논리탐험대는 ‘탐험 시작’을 사용하며 다른 다섯 프로젝트의 문구는 유지합니다. 캐릭터 이름·주제·미디어 경로는 해당 항목의 `characters`에서 관리합니다.

실제 앱 이미지를 등록하려면 `screenshot`에 상대경로를 넣으세요. 로딩 실패 시 해당 프로젝트의 소개 비주얼로 돌아갑니다. 이미지에 개인정보나 공개하면 안 되는 운영 데이터가 없는지 먼저 확인해야 합니다.

### 구성 파일

```text
index.html              # 페이지 골격
styles.css              # 기존 스타일 + 논리 카드 전용 모션
projects.js             # 6개 프로젝트 / 캐릭터 메타데이터
visuals.js              # 소개 비주얼과 논리 카드 HTML 골격
app.js                  # 가로 탐색 / 상세보기 / 캐릭터 선택
sw.js                   # 포트폴리오 범위의 선택적 캐시
manifest.webmanifest    # 홈화면 설치 메타데이터
logic-*-portrait.webp   # 원본 이미지의 캐릭터 구역 3개
logic-*-room.webp       # 원본 이미지의 배경 구역 3개
README.md               # 이 문서
```

아이콘 파일과 `.nojekyll`도 포함합니다. 외부 애니메이션 프레임워크, 분석 코드, 외부 폰트, 별도 빌드 도구를 추가하지 않았습니다.

## 📦 미디어와 저장 공간

원본 2×2 이미지 시트에서 세 캐릭터의 좌상단 포즈와 우하단 배경을 크롭했습니다. 얼굴·머리카락·의상을 새로 생성하거나 흰색을 일괄 제거하지 않았습니다. WebP 6개 합계는 **413,586바이트**입니다.

첫 STOCK LAB 카드에서 논리 이미지를 미리 불러오지 않습니다. 논리 카드가 가까워지면 세 캐릭터와 선택된 배경만 준비하고, 나머지 배경은 선택할 때 불러옵니다. 이미지가 실패해도 전용 대체 화면과 ‘탐험 시작’ 링크를 사용할 수 있습니다.

서비스워커는 이 포트폴리오의 정확한 파일 경로만 처리합니다. 핵심 파일과 달리 신규 이미지는 설치 시 일괄 저장하지 않고, 요청한 이미지만 선택적으로 캐시합니다. 다른 앱의 저장 키·IndexedDB·캐시는 초기화하지 않습니다. 캐릭터 선택은 현재 방문 중에만 유지하며 학습 데이터에 기록하지 않습니다.

서비스워커나 미디어를 업데이트할 때는 `sw.js`의 버전과 새 파일 허용 목록도 함께 검토하세요. 오프라인 구성은 **연결된 모든 앱이 오프라인으로 실행된다는 뜻이 아닙니다.**
